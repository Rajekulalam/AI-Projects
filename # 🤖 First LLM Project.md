# 🤖 First LLM Project

A simple Local LLM Chatbot built with Python and Hugging Face Transformers.

## 🚀 Features

- Local AI Chat
- Python
- Hugging Face Transformers
- Offline Inference

## 📁 Project Structure

```
First-LLM-Project/
├── app.py
├── chat.py
├── requirements.txt
├── README.md
├── models/
├── data/
├── utils/
└── outputs/
```

## 🛠 Installation

```bash
pip install -r requirements.txt
```

## ▶️ Run

```bash
python chat.py
```
