# 🤖 Local AI Assistant

A professional Local AI Chatbot built with Python, Streamlit and Ollama.

## ✨ Features

- 🤖 Local AI Chat
- 💬 Chat History
- 🧠 Multiple Models
- ⚡ Fast Response
- 🎨 Clean UI
- 🔒 Runs Completely Offline

## 🛠️ Technologies

- Python
- Streamlit
- Ollama
- Gemma 3

## 🚀 Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
